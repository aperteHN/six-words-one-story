A Node 22 program with no dependencies that writes one complete story
in exactly six words, "He practiced proposing; she practiced leaving.",
to the output directory as entry.txt, byte for byte the same on every
run. Two people rehearsing opposite futures: that is the whole story,
and the outcome is left unsaid.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
